Dustpan OFFLINE

Sweep bitcoin across hardware, hot & paper wallets

Backend: ▼

Point the current network at your own esplora-compatible server (electrs, a self-hosted mempool instance backed by Fulcrum, or Blockstream's esplora) instead of mempool.space, so your addresses never leave your network. Only same-origin, mempool.space, and localhost/127.0.0.1 backends are allowed — see the README's "Use your own node" section for why and how.

1. Create PSBT

Add inputs from each wallet by fetching UTXOs, set the outputs and fee, then download the unsigned PSBT file. Remove individual UTXOs from the list if you don't want to spend the entire wallet.

Add addresses, WIFs, xpubs, etc.

Offline build — UTXO lookups need a network, so add each one manually with + Add Input (txid, vout, value in sats, scriptPubKey), or build the PSBT on another device and upload/scan it below to sign.
